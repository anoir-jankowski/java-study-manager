# Java Study Manager

My first independent Java project, developed alongside my Computer Science studies at Karlsruhe University of Applied Sciences (HKA).

The goal of this project is to build a simple command-line application for organizing university courses and study tasks while practicing Java and object-oriented programming.

## Current Progress

- Created separate `Main`, `Course`, and `Task` classes
- Implemented attributes and constructors
- Created objects and connected tasks to courses
- Practiced accessing object data using getter methods

## Planned Features

- Create and manage courses and tasks
- Add deadlines and priorities
- Mark tasks as completed
- View and organize tasks through a command-line menu
- Save and load task data

## Technologies

- Java
- Git & GitHub
- IntelliJ IDEA

## What I'm Learning

- Object-oriented programming (OOP)
- Classes and objects
- Constructors and attributes
- Methods and encapsulation
- Structuring a Java project

## Project Status

**In Progress**

The project currently demonstrates basic classes, objects, and their relationships. The interactive task management features are not yet implemented.

I am developing the application step by step as I continue learning Java.
